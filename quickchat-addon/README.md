# クイックチャット（人狼用）アドオン

統合版マイクラ用。アイテムを使うと定型文メニューが開き、**半径12マス以内の人にだけ**チャットが届きます。VCが使えない人向けです。

## 導入
1. `QuickChat.mcaddon` を開いてマイクラに取り込む
2. 配布ワールドの「ワールドの編集」→ ビヘイビアーパック / リソースパックで **クイックチャット BP / RP** を有効化（実験的機能は不要）
3. ゲーム内でアイテムを配る

```
/give @a qc:quick_chat 1 0 {"keep_on_death":{},"item_lock":{"mode":"lock_in_inventory"}}
```
（`keep_on_death` で死んでも消えず、`item_lock` で捨てられなくなります）

## 使い方
アイテムを持って右クリック（スマホはタップ長押し）でメニューを開きます。

- **最近使ったもの** … 直近5件を再送
- **返事・リアクション / 疑い・推理 / 目撃・アリバイ / 自分について・CO / 結果報告 / 行動・指示 / 質問・議論**
  - `〇〇` が入った文は、次の画面でプレイヤーを選ぶと名前が入ります
- **自由入力** … 好きな文章を送れます（最大60文字）

## 人狼向けの仕組み
| 状況 | 動き |
|---|---|
| 生存者が送信 | 12マス以内の全員 ＋ 死亡者全員（距離無関係）に届く |
| 死亡者が送信 | **死亡者全員にだけ**届く（距離無関係、`[霊界]` 表示） |
| 死亡者の判定 | `dead` タグ付き、またはスペクテイターモード |
| 発言禁止（夜など） | `/tag @a add qc_mute` で使用不可、`/tag @a remove qc_mute` で解除 |
| 連投防止 | 2秒のクールダウン |

死亡タグを付けるには `/tag <名前> add dead` を使います。配布ワールドが別のタグを使っている場合は `config.js` の `DEAD_TAG` をそれに合わせてください。

## カスタマイズ
- `QuickChat_BP/scripts/config.js` … 範囲、クールダウン、タグ名、効果音など
- `QuickChat_BP/scripts/messages.js` … 定型文の追加・変更（`{p}` がプレイヤー名に置き換わる）

変更後は `python3 build.py` で `QuickChat.mcaddon` を作り直します。
